# Iconoclast Bot

Iconoclast is a bot for discord that offers an array of different utilities and features for server owners and users.  
Some features of the bot are:  
Expansive inter-server stock market using bot currency, invest into server stocks.  
In-depth Karma system.  
Auto-deletion of messages.  
Easy user webhook-proxying of messages and images.  
Easily-readable message logs that are natural and not crowded via embeds.  
Moderation and automod systems.  
An experience system with server and global leaderboards.  
Easy to setup role menus.  
Tickets.  
Hall of Fame and Shame.  
And more.
